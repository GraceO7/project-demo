# BECE Question Demo

This is a simple demo showing how a BECE question bank works in a web app.

- Questions are stored as JSON files in `public/data/BECE/`
- Subjects: Mathematics, English, Science
- Each question includes: id, question, options (A–D), answer, and explanation

How it works:
1. Select a subject from the dropdown.
2. The first question loads with options.
3. Click an option to see if it’s correct along with an explanation.
4. Click "Next Question" to move to the next one.

This is just a placeholder/demo. Real questions can be added easily without changing the structure.
